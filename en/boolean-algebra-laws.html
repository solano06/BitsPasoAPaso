The 7 Logic Gates (ANSI/IEEE)

GateSymbolExpressionTruth TableNote
NOT Y = A' = ¬A 0→1, 1→0 Logical inverter
AND Y = A·B = A ∧ B 00→0, 01→0, 10→0, 11→1 Output 1 only if all inputs are 1
OR Y = A + B = A ∨ B 00→0, 01→1, 10→1, 11→1 Output 1 if at least one input is 1
NAND Y = (A·B)' = ¬(A ∧ B) 00→1, 01→1, 10→1, 11→0 Universal gate (can build any function)
NOR Y = (A + B)' = ¬(A ∨ B) 00→1, 01→0, 10→0, 11→0 Universal gate
XOR Y = A ⊕ B 00→0, 01→1, 10→1, 11→0 Output 1 when inputs differ
XNOR Y = (A ⊕ B)' = A ↔ B 00→1, 01→0, 10→0, 11→1 Equality comparator (1 if A == B)

Fundamental Boolean Algebra Laws

LawEngineering (+, ·, ')Logic (∨, ∧, ¬)
Identity A + 0 = A | A·1 = A A ∨ 0 = A | A ∧ 1 = A
Domination (Null) A + 1 = 1 | A·0 = 0 A ∨ 1 = 1 | A ∧ 0 = 0
Idempotence A + A = A | A·A = A A ∨ A = A | A ∧ A = A
Complement A + A' = 1 | A·A' = 0 A ∨ ¬A = 1 | A ∧ ¬A = 0
Double Negation (A')' = A ¬(¬A) = A
Commutative A + B = B + A | A·B = B·A A ∨ B = B ∨ A | A ∧ B = B ∧ A
Associative (A + B) + C = A + (B + C) (A ∨ B) ∨ C = A ∨ (B ∨ C)
Distributive A·(B + C) = A·B + A·C A ∧ (B ∨ C) = (A ∧ B) ∨ (A ∧ C) Check equivalence
Absorption A + A·B = A | A·(A + B) = A A ∨ (A ∧ B) = A Check equivalence
Consensus A·B + A'·C + B·C = A·B + A'·C (A ∧ B) ∨ (¬A ∧ C) ∨ (B ∧ C) = (A ∧ B) ∨ (¬A ∧ C) Check equivalence

Frequently asked questions

Why are NAND and NOR universal gates? +

Any Boolean function (including NOT, AND, OR) can be built using only NAND gates or only NOR gates.

What do De Morgan’s laws state? +

The complement of a sum equals the product of complements, and the complement of a product equals the sum of complements.

Can I verify these laws step by step? +

Yes, click "Check equivalence" to open the Truth Table generator with both sides preloaded.

When should I use Karnaugh Maps? +

To systematically minimize 2–4 variable functions into minimal SOP or POS.
