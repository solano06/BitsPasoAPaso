Lois d’Algèbre de Boole, De Morgan et Portes Logiques

Les 7 portes logiques en SVG ANSI/IEEE, les lois fondamentales en double notation et boutons de vérification en Table de Vérité.

Les 7 Portes Logiques (ANSI/IEEE)

PorteSymboleExpressionTableNote
NOT Y = A' = ¬A 0→1, 1→0 Inverseur logique
AND Y = A·B = A ∧ B 00→0, 01→0, 10→0, 11→1 Sortie 1 si toutes les entrées valent 1
OR Y = A + B = A ∨ B 00→0, 01→1, 10→1, 11→1 Sortie 1 si au moins une entrée vaut 1
NAND Y = (A·B)' = ¬(A ∧ B) 00→1, 01→1, 10→1, 11→0 Porte universelle
NOR Y = (A + B)' = ¬(A ∨ B) 00→1, 01→0, 10→0, 11→0 Porte universelle
XOR Y = A ⊕ B 00→0, 01→1, 10→1, 11→0 Sortie 1 si les entrées diffèrent
XNOR Y = (A ⊕ B)' = A ↔ B 00→1, 01→0, 10→0, 11→1 Comparateur d’égalité (1 si A == B)

Lois Fondamentales de l’Algèbre de Boole

LoiIngénierie (+, ·, ')Logique (∨, ∧, ¬)
Identité A + 0 = A | A·1 = A A ∨ 0 = A | A ∧ 1 = A
Élément absorbant A + 1 = 1 | A·0 = 0 A ∨ 1 = 1 | A ∧ 0 = 0
Idempotence A + A = A | A·A = A A ∨ A = A | A ∧ A = A
Complément A + A' = 1 | A·A' = 0 A ∨ ¬A = 1 | A ∧ ¬A = 0
Double négation (A')' = A ¬(¬A) = A
Commutativité A + B = B + A | A·B = B·A A ∨ B = B ∨ A | A ∧ B = B ∧ A
Associativité (A + B) + C = A + (B + C) (A ∨ B) ∨ C = A ∨ (B ∨ C)
Distributivité A·(B + C) = A·B + A·C A ∧ (B ∨ C) = (A ∧ B) ∨ (A ∧ C) Vérifier l’équivalence
Absorption A + A·B = A | A·(A + B) = A A ∨ (A ∧ B) = A Vérifier l’équivalence
Consensus A·B + A'·C + B·C = A·B + A'·C (A ∧ B) ∨ (¬A ∧ C) ∨ (B ∧ C) = (A ∧ B) ∨ (¬A ∧ C) Vérifier l’équivalence

Questions fréquentes

Pourquoi NAND et NOR sont-elles universelles ? +

Toute fonction booléenne peut être réalisée uniquement avec des portes NAND ou uniquement avec des portes NOR.

Qu’énoncent les théorèmes de De Morgan ? +

Le complément d’une somme est le produit des compléments, et inversement.

Puis-je vérifier ces lois étape par étape ? +

Oui, cliquez sur « Vérifier l’équivalence » pour ouvrir la Table de Vérité préremplie.

Quand utiliser les tableaux de Karnaugh ? +

Pour minimiser systématiquement des fonctions de 2 à 4 variables.
